Za spremanje promjena na github:
U terminalu (ako ga ne vidis, odes na alatnu traku na vrhu VS Coda i kliknes Terminal -> New terminal)

1. git add .
2. git commit -m "ovdje upisi poruku promjena, npr dodane margine"
3. git push origin main
